# 3-4 minute video script

**0:00 - Hook (15s).** "Customer service re-types orders and chases missing details. I built the intake layer that removes both - here it is running on 100 messy orders."

**0:15 - Demo 1: touchless (45s).** Show a PDF purchase order email. Run it. Point to: extraction -> validation checks -> Business Central order -> HubSpot deal -> one confirmation email. "One email out, zero touches."

**1:00 - Demo 2: exception (60s).** Open a case with three problems. Show the single bundled clarification draft. Show a near-miss part number: "it suggests, it never guesses." Apply the fix, re-validate, confirmed, audit trail.

**2:00 - Results (30s).** Dashboard: touchless rate, emails per case, exceptions by reason. Say which numbers are measured and which are modeled from adjustable assumptions.

**2:30 - Design choices (30s).** AI reads, code decides. Mock ERP and CRM here, live clients written but not run. A CRM outage never loses an order.

**3:00 - Roadmap (30s).** Week 1 map one real order flow; weeks 2-4 pilot on one customer segment; then portal, then procurement/inventory. "I'd start with your top three order-entry error types."

**Close (10s).** Availability and US-hours overlap.
